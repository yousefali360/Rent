# Housely بنها | محرك البحث الذكي عن شقق الإيجار (القليوبية)

تطبيق ويب عربي متكامل (**Full-Stack**) مبني باستخدام **React + TypeScript + Vite** للواجهة الأمامية المستوحاة من نظام تصميم **[Housely Real Estate UI Kit](https://www.figma.com/design/A8vdGgPPYkBPSIV2dF2Cyj/Housely---Rent-Real-Estate-App-Ui-Kit--Community-?node-id=446-5021&m=dev&t=r08ClylFiO7x6rh4-1)** و **Python + FastAPI + SQLite** للخادم الخلفي، مخصص للبحث عن منشورات شقق الإيجار العامة في مصر بدءًا بمنطقة **بنها، محافظة القليوبية**.

---

## 1. المميزات الأساسية المنفذة

1. **واجهة عقارات احترافية بنظام تصميم Housely (RTL):**
   - تصميم عقاري متجاوب مع الكمبيوتر والموبايل بألوان ملكية عصرية (Royal Blue & Emerald).
   - بطاقات عقارات مميزة (`Property Cards`) تعرض السعر البارز، حالة التوثيق، شريط مواصفات بأيقونات Lucide (غرف، حمامات، مساحة م²، حالة الفرش).
   - نافذة تفاصيل العقار الشاملة (`Property Details Sheet`) مع زر اتصال هاتفي وزر واتساب مباشر.
   - ميزة حفظ العقارات في المفضلة (`Favorites`) في المتصفح.
   - شريط أحياء بنها التفاعلي للتصفية السريعة بضغطة واحدة (`الفلل`، `الكورنيش`، `وسط البلد والمحطة`، `منطقة الجامعة والطب`، `مساكن طابا والموقف`، `كفر الجزار`، `أتريب`، `المنشية`، `الأهرام`، `الحرس الوطني`).
   - التمييز الدقيق بين **«بنها»** و**«بنها الجديدة»** وعدم دمجهما تلقائيًا دون سياق.

2. **الفلاتر الزمنية الصارمة بتوقيت مصر (`Africa/Cairo`):**
   - دعم الفترات: **آخر 24 ساعة**، **آخر يومين**، **آخر 4 أيام (القيمة الافتراضية)**، و**فترة مخصصة (من تاريخ ووقت إلى تاريخ ووقت)**.
   - تطبيق الفلترة على **تاريخ نشر المنشور الأصلي** وليس تاريخ فهرسته أو جلبه.
   - استبعاد المنشورات الأقدم من الفترة المطلوبة تلقائيًا.
   - عرض المنشورات التي تعذّر التحقق من تاريخ نشرها في قسم مستقل بعنوان **«تاريخ النشر غير مؤكد»**.

3. **بنية مصادر البحث القابلة للتوسعة (`Search Providers`):**
   - **المصدر الأول (Facebook):** توليد روابط بحث مخصصة داخل Facebook بفلتر «الأحدث» (Recent Posts) وروابط الجروبات العامة وأحياء بنها الفرعية، بالإضافة إلى ميزة **الاستيراد المصرح به الذي يبدأه المستخدم بنفسه** دون طلب كلمة مرور أو تخزين ملفات ارتباط.
   - **المصدر الثاني (محركات البحث العامة):** وحدات مستقلة قابلة للاستبدال تشمل:
     - `PublicWebIndexProvider` (فهرس الويب العام عبر DuckDuckGo HTML).
     - `GoogleCSEProvider` (واجهة Google Custom Search JSON API الرسمية).
     - `SerperProvider` (واجهة Serper.dev لنتائج بحث جوجل).
   - **التحقق من الروابط:** التمييز الآلي بين رابط المنشور الفعلي (`/posts/...`, `/permalink/...`, `story_fbid=...`) ورابط الصفحة الرئيسية للجروب العام، وعدم عرض رابط غير متحقق منه باعتباره رابط المنشور الأصلي.

4. **استخراج البيانات وإزالة التكرارات:**
   - استخراج السعر الشهري بالجنيه المصري، عدد الغرف والحمامات، المساحة بالمتر المربع، حالة الفرش، ووسيلة التواصل دون اختلاق أي بيانات غير موجودة في المصدر.
   - اكتشاف التكرار التام وإزالته، مع الاحتفاظ بالمنشورات المتشابهة جزئيًا التي قد تختلف في السعر أو التفاصيل مع وضع شارة **«قد يكون مكررًا»** منعًا للدمج الخاطئ.

## 3. خطوات التشغيل على Windows و VS Code

### أولاً: إعداد البيئة الخلفية (Python + FastAPI)

افتح نافذة الطرفية (**Terminal -> PowerShell**) داخل مجلد المشروع في **VS Code**:

```powershell
# 1. إنشاء البيئة الافتراضية (إذا لم تكن موجودة)
py -m venv .venv

# 2. تثبيت المكتبات المطلوبة داخل البيئة الافتراضية
.\.venv\Scripts\pip.exe install -r requirements.txt

# 3. نسخ ملف الإعدادات البيئية (اختياري لإضافة مفاتيح Google CSE أو Serper)
Copy-Item .env.example .env -ErrorAction SilentlyContinue
```

### ثانيًا: تشغيل الاختبارات الآلية (Pytest)

للتحقق من عمل جميع الوحدات (التواريخ بتوقيت مصر، التطبيع العربي، استخراج الأسعار، التحقق من الروابط، وإزالة التكرارات):

```powershell
.\.venv\Scripts\pytest.exe -v
```

### ثالثًا: بناء أو تشغيل الواجهة الأمامية (React + TypeScript)

```powershell
cd frontend
npm install
npm run build
cd ..
```

### رابعًا: تشغيل التطبيق المتكامل

يمكنك تشغيل الخادم الخلفي والواجهة الأمامية معًا عبر الأمر التالي من جذر المشروع:

```powershell
.\.venv\Scripts\uvicorn.exe backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```

ثم افتح المتصفح على الرابط:
- **الواجهة العربية الكاملة:** `http://127.0.0.1:8000`
- **توثيق الـ API التفاعلي (Swagger UI):** `http://127.0.0.1:8000/docs`
- **فحص حالة النظام:** `http://127.0.0.1:8000/api/health`

*(أو لتشغيل خادم تطوير Vite منفصلًا أثناء تعديل الواجهة الأمامية: شغّل `npm run dev` داخل مجلد `frontend` ليفتح على `http://localhost:5173` مع توجيه تلقائي لطلبات `/api` إلى المنفذ `8000`).*

## 4. ما يعمل فورًا وما يحتاج إلى مفاتيح خارجية

| الميزة / المكوّن | الحالة الحالية | هل يحتاج مفتاحًا خارجيًا؟ |
| :--- | :--- | :--- |
| الواجهة العربية RTL والفلاتر الزمنية (`Africa/Cairo`) | يعمل بالكامل ✅ | لا |
| توليد روابط بحث Facebook المخصصة والجروبات العامة | يعمل بالكامل ✅ | لا |
| الاستيراد المصرح به للمنشورات وتحليلها وحفظها في SQLite | يعمل بالكامل ✅ | لا |
| التطبيع العربي واستخراج الأسعار والغرف والمساحة والفرش | يعمل بالكامل ✅ | لا |
| التحقق من روابط المنشورات وإزالة التكرارات | يعمل بالكامل ✅ | لا |
| فهرس الويب العام (`PublicWebIndexProvider`) | يعمل (خاضع لحدود طلبات محرك البحث العام) ✅ | لا |
| مزود `Google Custom Search JSON API` | جاهز ومبرمج بالكامل 🔑 | نعم (`GOOGLE_CSE_API_KEY` و `GOOGLE_CSE_CX` في `.env`) |
| مزود `Serper.dev Google Search API` | جاهز ومبرمج بالكامل 🔑 | نعم (`SERPER_API_KEY` في `.env`) |
| قراءة جميع منشورات جروبات فيسبوك آليًا | غير متاح تقنيًا/قانونيًا من Meta بدون شراكة رسمية 🔒 | يتطلب موافقة Meta الرسمية؛ تم توفير الروابط المباشرة والاستيراد المصرح به كبديل مشروع |
